Faculty Management System

A simple and user-friendly Faculty Management System developed using Python, Tkinter, and Excel. This project helps manage faculty records efficiently with features such as login authentication, adding, viewing, searching, updating, and deleting faculty information.

Features

- 🔐 Login Authentication
- 📊 Dashboard
- ➕ Add Faculty Records
- 👀 View Faculty Records
- 🔍 Search Faculty
- ✏️ Update Faculty Information
- 🗑️ Delete Faculty Records
- 🔄 Clear / Reset Form
- 🚪 Logout
- 📁 Excel-based Data Storage

Technologies Used

- Python
- Tkinter
- OpenPyXL
- Excel

This project was developed as a Python Mini Project to demonstrate GUI development, file handling, and CRUD operations using Excel.
